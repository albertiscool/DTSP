================================================================================
無人機動態威脅巡航路徑規劃系統 (DTSP) 使用說明
================================================================================

本說明文件提供本套件之環境安裝、主程式操作、資料庫與腳本執行方式。


================================================================================
一、環境需求與安裝步驟
================================================================================

1. Python 環境需求：
   建議使用 Python 3.10 至 3.12 版本。

2. 建議建立乾淨的虛擬環境 (以 Conda 為例)：
   conda create -n dtsp_env python=3.12 -y
   conda activate dtsp_env

   (或使用 Python 內建 venv)：
   python -m venv dtsp_env
   dtsp_env\Scripts\activate      [Windows]
   source dtsp_env/bin/activate   [Linux / macOS]

3. 安裝必要套件：
   在 DTSP_Package 資料夾內開啟終端機，執行：
   pip install -r requirements.txt

   * 附註：
     - 若具備 NVIDIA 獨立顯卡，程式會自動使用 CUDA 加速。
     - 若無獨立顯卡，程式會自動切換為 CPU 運算，可正常執行所有功能。


================================================================================
二、主程式執行方式 (main.py)
================================================================================

在 DTSP_Package 資料夾目錄下，提供兩種執行方式：

--------------------------------------------------------------------------------
【方法一】互動選單模式 (推薦直接展示)
--------------------------------------------------------------------------------
在終端機輸入：
python main.py

終端機會顯示下列數字選單，依需求輸入編號後按 Enter 即可：

  [1] 執行 Stage 0 ~ Stage 5 突發防空威脅演進模擬 (生成各階段航跡圖)
  [2] 執行 臺灣東南海域 1:1 真實地理比例尺實境戰術圖 (志航基地/綠島/蘭嶼)
  [3] 執行 50 組隨機未知地圖 (Seeds 51-100) 泛化與幾何邊界診斷
  [4] 繪製 三大演算法 (CaR vs LKH vs SA) 核心指標與盒鬚圖
  [5] 一鍵編譯產出 25 頁 Word 完整技術報告書 (.docx)
  --------------------------------------------------------------------
  [A] 依序執行全部任務 (Run All Demos & Build Report)
  [0] 離開系統 (Exit)

--------------------------------------------------------------------------------
【方法二】命令列參數模式 (適合批次自動化運算)
--------------------------------------------------------------------------------
可直接帶入旗標參數執行指定功能：

- 依序執行全部任務並產出報告：
  python main.py --all

- 執行各階段突發威脅避障演進模擬：
  python main.py --stage

- 執行臺灣東南海域 1:1 實境戰術模擬：
  python main.py --taiwan

- 執行 50 組未知隨機地圖測試：
  python main.py --unseen

- 繪製三大演算法效益對比圖：
  python main.py --compare

- 編譯產出 25 頁 Word 完整技術報告書：
  python main.py --report


================================================================================
三、獨立腳本執行方式 (scripts/ 目錄)
================================================================================

若需單獨除錯或修改特定腳本參數，可直接執行 scripts/ 內的程式：

- 執行階段演進模擬：
  python scripts/1_run_stage_benchmarks.py

- 執行臺灣海域戰術模擬：
  python scripts/2_run_taiwan_simulation.py

- 執行未知隨機地圖測試：
  python scripts/3_run_unseen_benchmark.py

- 繪製演算法對比圖表：
  python scripts/4_plot_comparison_metrics.py

- 編譯 Word 技術報告書：
  python scripts/5_build_word_report.py


================================================================================
四、資料庫與產出目錄說明
================================================================================

1. data/ 資料夾 (完整原始實驗數值數據)：
   內含本研究所產出之所有演算法基準測試數據與軌跡數值快取：
   - three_methods_benchmark_results.csv : SA、Transformer 與 CaR 之 20 組航程、耗時與碰撞次數原始數據
   - unseen_51_100_results.csv           : 50 組未知地圖盲測數據 (Seeds 51-100)
   - unseen_50_results.csv               : 50 組隨機未知地圖完整評估數據
   - oneshot_comparison_results.csv      : 基準、可見度走廊與 CaR 架構 50 組對比數據
   - monte_carlo_50_results.csv          : 50 組蒙地卡羅多階段動態威脅演進數據
   - monte_carlo_100_step1.csv           : 100 組蒙地卡羅基準測試數據
   - stage5_solved_cache.npz             : 臺灣東南海域 Stage 5 最佳化軌跡座標、插值航路點與距離快取

2. output/ 資料夾 (程式產出之圖表與報告)：
   執行程式後，生成之所有 300 DPI 高畫質戰術航跡圖、統計盒鬚圖、柱狀圖與技術報告書
   均會自動儲存於此目錄。

3. docs/ 資料夾 (技術報告書)：
   內含已排版完成之 Word 技術報告：
   - 無人機動態威脅巡航路徑規劃.docx


================================================================================
五、注意事項
================================================================================

1. 在執行 [5] 或 --report 編譯 Word 報告時，若微軟 Word 正在開啟 output 目錄下的
   技術報告書，可能會因檔案被鎖定而出現權限錯誤。請在執行前先關閉該 Word 檔案。

2. 繪圖腳本已內建中文字型設定，Windows 系統優先調用「微軟正黑體」，無需額外安裝字型。
